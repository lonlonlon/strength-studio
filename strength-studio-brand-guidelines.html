Section 01

Colour Palette

A palette built on contrasts that don't compete. The dark anchor grounds without intimidating. The warm surfaces invite without feeling soft. The accents activate without shouting. Every tone is calibrated to feel like a space you'd want to spend time in — more private studio than public gym.

Section 02

Usage Proportions

The 60-30-10 rule adapted for a dual-accent system. Warm neutrals dominate. Ember and Basalt are used sparingly for maximum impact.

Canvas + Linen + White 60%
Backgrounds, surfaces, breathing room. The dominant visual experience.
Ironstone + Charcoal + Flint 25%
Text, navigation, dark sections. Grounding presence throughout.
Ember 10%
Primary accent. CTAs, links, monogram, active states. Every instance should feel intentional.
Basalt 5%
Secondary accent. Recovery content, promotional moments, supporting tags. Rarer than Ember.

When to use gradients
Social media graphics and stories, promotional banners, event collateral, Instagram highlight covers, email headers, branded merchandise, seasonal website hero sections, presentation decks for corporate wellness pitches.
When NOT to use gradients
Core website page backgrounds (keep those solid), the logo itself (always flat colour), body text areas, pricing tables, forms, navigation, and day-to-day brand communications. The gradient is a special treatment — overuse dilutes its impact.

Section 06

Usage Rules

Key principles that keep the brand consistent across all touchpoints.

Special Gothic Expanded One is logotype-only
Never use for headlines, body text, buttons, or any UI element. It appears only in the brand name lockup (STRENGTH / STUDIO) and the monogram mark (S).
Manrope handles everything else
Headlines, body, navigation, CTAs, forms, labels, metadata, social captions. One font family, multiple weights — keep it simple.
Instrument Serif is an accent, not a workhorse
Reserve for the tagline, pull quotes, testimonials, blog drop caps, and occasional editorial headlines. If it appears more than once per screen, it's overused.
Ember is for action, Basalt is for recovery
Never swap them. Training labels, primary CTAs, and active states always use Ember. Recovery labels, physio tags, and secondary promotions always use Basalt.
Gradients are special occasions
Social media, merch, campaigns, seasonal heroes. Never on core website backgrounds, forms, or pricing tables. Maximum 3 colour stops per gradient. Transitions always soft (no hard lines), default angle 135°.
No GoFit reference
Strength Studio operates as a completely separate brand. The only parent company reference is "JSF Transformative Pte Ltd" in footer copyright lines and legal documents.
