Section 02

Usage Proportions

The 60-30-10 rule adapted for a dual-accent system. Warm neutrals dominate. Ember and Basalt are used sparingly for maximum impact.

Canvas + Linen + White 60%
Backgrounds, surfaces, breathing room. The dominant visual experience.
Ironstone + Charcoal + Flint 25%
Text, navigation, dark sections. Grounding presence throughout.
Ember 10%
Primary accent. CTAs, links, monogram, active states. Every instance should feel intentional.
Basalt 5%
Secondary accent. Physio content, promotional moments, supporting tags. Rarer than Ember.

Section 03

Gradient System

Four named gradients built from the brand palette. Used as a secondary texture layer for social media, promotional materials, branded merch, and seasonal campaign moments. Never used for core website backgrounds, the logo, or day-to-day brand communications.

Forge
The signature gradient. Ironstone through Basalt into Ember — cold metal heated until it glows. Maps to the training philosophy: start grounded, build through physio, ignite results.
→
→
Duality
Physio to training in a single sweep. Basalt fades through Linen into Ember — the calm-to-action transition. Best for content that spans both brand pillars.
→
→
Depth
The moody, physio-focused gradient. Dark tones only — Ironstone through Charcoal into Basalt. Atmospheric and calm. Best for physio content, evening social posts, meditative brand moments.
→
→
Anneal
Ember darkening through deep brick into Charcoal. Named after the metalworking process of heating and slow-cooling. The high-energy option — good for launch campaigns, merch, and high-impact visuals.
→
→
When to use gradients
Social media graphics and stories, promotional banners, event collateral, Instagram highlight covers, email headers, branded merchandise, seasonal website hero sections, presentation decks for corporate wellness pitches.
When NOT to use gradients
Core website page backgrounds (keep those solid), the logo itself (always flat colour), body text areas, pricing tables, forms, navigation, and day-to-day brand communications. The gradient is a special treatment — overuse dilutes its impact.

Section 04

Typography

A three-font system: an industrial expanded sans for the logotype, a versatile geometric sans for everything else, and a refined serif for accent moments. All open-source via Google Fonts.

Logotype — Special Gothic Expanded One

A multi-width gothic typeface designed by Alistair McCready (Monolith, NZ). The expanded width gives "STRENGTH" a wide, commanding presence — each letter occupies space with quiet authority. Used exclusively for the logotype and brand name lockup. Never for body copy, headlines, or UI elements.

Section 06

Usage Rules

Key principles that keep the brand consistent across all touchpoints.

Special Gothic Expanded One is logotype-only
Never use for headlines, body text, buttons, or any UI element. It appears only in the brand name lockup (STRENGTH / STUDIO) and the monogram mark (S).
Rethink Sans handles everything else
Headlines, body, navigation, CTAs, forms, labels, metadata, social captions. One font family, multiple weights — keep it simple.
Instrument Serif is an accent, not a workhorse
Reserve for the tagline, pull quotes, testimonials, blog drop caps, and occasional editorial headlines. If it appears more than once per screen, it's overused.
Ember is for action, Basalt is for physio
Never swap them. Training labels, primary CTAs, and active states always use Ember. Physio labels, physio tags, and secondary promotions always use Basalt.
Gradients are special occasions
Social media, merch, campaigns, seasonal heroes. Never on core website backgrounds, forms, or pricing tables. Maximum 3 colour stops per gradient. Transitions always soft (no hard lines), default angle 135°.
No GoFit reference
Strength Studio operates as a completely separate brand. The only parent company reference is "JSF Transformative Pte Ltd" in footer copyright lines and legal documents.
